## But don't forgot install fonts and themes
[Font repo](https://github.com/subframe7536/maple-font)
```bash
# Maple Mono
brew install --cask font-maple-mono
# Maple Mono NF
brew install --cask font-maple-mono-nf
# Maple Mono NF CN
brew install --cask font-maple-mono-nf-cn
```
